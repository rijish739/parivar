# Parivar

Parivar is a matrimony application built exclusively for the Bunt community.

## Included

- TanStack Start + React application
- Lovable Cloud authentication and data access
- Profile onboarding, matching, interests, search, messaging, and admin review
- Database migrations under `supabase/migrations`

## Local development

Install dependencies with Bun, configure the required public environment variables, then run `bun run dev`.

Private environment files and generated internal skill files are intentionally excluded from this repository.
